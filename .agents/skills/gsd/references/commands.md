# GSD Command Reference

## Core Innovation Pillars

| Command | Profile | What it does |
|---|---|---|
| `/gsd-super [prompt]` | **Autonomous** | Full autonomy: AI plans, executes, tests, and delivers |
| `/gsd-no-halluc [q]` | **Verified** | Technical Q&A with mandatory external verification |
| `/gsd-commit-memory` | **Continuity** | Distills architectural decisions into project memory |

## Standard Workflow

| Command | Task | Description |
|---|---|---|
| `/gsd-new-project` | **Setup** | Gather requirements, define project vision, build roadmap |
| `/gsd-discuss [N]` | **Context** | Lock in phase-specific technical decisions |
| `/gsd-plan [N]` | **Blueprint** | Generate atomic task plans and research for Phase N |
| `/gsd-execute [N]` | **Builder** | Execute all plans with atomic git commits |
| `/gsd-verify [N]` | **Audit** | Run verification checks and user acceptance tests |
| `/gsd-progress` | **Status** | Current state, progress metrics, and next actions |
| `/gsd-quick [task]` | **Ad-hoc** | Quick task with standard GSD quality gates |
| `/gsd-help` | **Reference**| Display complete command guide |
