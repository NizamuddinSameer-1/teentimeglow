# Plan 15-2: Overhaul Article Rich-Text Editor & Live Story Preview Modal

## Objective
Upgrade `RichTextEditor.astro` to solve the broken in-between photo insertion issue by preserving DOM Selection Ranges, introduce an Affiliate Hyperlink modal with automatic `rel="sponsored noopener"`, add alignment/divider controls, and implement a live article preview modal in `/admin`.

## Code Patterns (Model Resilience)
Reference these existing files:
- `src/components/admin/RichTextEditor.astro` — Current toolbar and contenteditable canvas
- `src/pages/edits/[slug].astro` — Reader typography and styles to mirror in the preview modal

Conventions:
- Do NOT use `execCommand('insertImage')` when focus is lost. Instead, capture `range.cloneRange()` on mousedown/focus and insert `<img>` or `<figure>` directly using `range.insertNode()`.
- Add affiliate link modal inside the editor wrapper with high z-index and clean form inputs.
- Ensure all inserted links have `target="_blank"` and `rel="sponsored noopener"`.
