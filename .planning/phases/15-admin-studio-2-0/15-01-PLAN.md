# Plan 15-1: Backend API & Data Layer for Quizzes & Posts Draft Status

## Objective
Build backend API endpoints and data fetchers to support dynamic quiz creation, updating, deletion, and full draft/published status toggling for articles and quizzes.

## Code Patterns (Model Resilience)
Reference these existing files for code style:
- `src/pages/api/admin/posts.ts` — Authentication check `checkAuth(cookies)` and error responses
- `src/pages/api/admin/rankings.ts` — CRUD handling in Astro serverless endpoints
- `src/lib/api.ts` — Resilient query pattern with fallback matching

Conventions:
- Always export `export const prerender = false;` on admin API routes
- Check admin session via `checkAuth(cookies)`
- Return JSON responses with explicit status codes (200, 400, 401, 500)
