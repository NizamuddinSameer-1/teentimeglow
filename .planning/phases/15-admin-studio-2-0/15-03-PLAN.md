# Plan 15-3: Interactive Quiz Studio Tab in Admin & Public Quiz Sync

## Objective
Deliver a dedicated "Interactive Quizzes" studio tab in `/admin` empowering Rini to dynamically create multi-question quizzes with custom options (Option 1, 2, 3, 4+), photo answers, archetype score mapping, edit/delete controls, and live quiz preview; and sync the public `/quiz` page to serve custom active quizzes.

## Code Patterns (Model Resilience)
Reference these existing files:
- `src/pages/admin/index.astro` — Tab switching (`switchTab`), photo upload boxes, and card actions
- `src/components/interactive/QuizPlayer.tsx` — Question and Option data structure
- `src/pages/quiz/index.astro` — Public quiz island mounting

Conventions:
- In the quiz builder state, keep a reactive JSON structure for `currentQuizQuestions`:
  ```javascript
  [
    {
      id: 1,
      indicator: "Morning Vibe",
      question: "What is your dream morning?",
      options: [
        { text: "Option 1: Matcha latte", outcomeKey: "clean_girl", imageUrl: "" },
        { text: "Option 2: Sunset photoshoot", outcomeKey: "sunset_muse", imageUrl: "" }
      ]
    }
  ]
  ```
- Use 1-click "➕ Add Question" and "➕ Add Option" buttons.
- Ensure every option allows selecting an archetype outcome (`sunset_muse`, `clean_girl`, `cozy_vanilla`, `downtown`).

## Must-Haves
- Rini can add multiple questions to a quiz, and add/remove options (Option 1, 2, 3, 4+) per question.

- Quizzes can be edited, deleted, or activated from the admin panel.
- Public `/quiz` route reflects the custom active quiz.
