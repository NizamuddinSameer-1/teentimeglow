# Plan 2-1: Modular Frontend Components, Client Directives & Manual Editability

## Objective
Fulfill Phase 2 requirements by ensuring all interactive UI components have proper Astro client directives (`client:visible`, `client:idle`), full TypeScript props interfaces connected to `src/config/siteContent.ts` for effortless 1-stop manual copy editing, and 100% visual design parity with original aesthetic.

## Code Patterns (Model Resilience)
Reference existing Astro & React patterns:
- Props interface with defaults: `const { title = siteContent.section.title } = Astro.props;`
- Centralized site copy in `@/config/siteContent.ts`
- Client directives on islands: `<Component client:visible />`, `<Component client:idle />`
