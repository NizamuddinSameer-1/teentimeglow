# Plan 16-02: Structured Data Enrichment (HowTo, FAQPage, and CreativeWork Schemas)

## Objective
Unlock Google Search rich snippets—including Mobile HowTo step cards, FAQ accordions, and CreativeWork image attributions—by enriching JSON-LD graphs in dynamic article and wallpaper routes.

## Code Patterns (Model Resilience)
Reference existing files:
- `src/pages/edits/[slug].astro`: Match existing `articleSchema` and `breadcrumbSchema` object structure and `@id` linking.
- `src/layouts/BaseLayout.astro`: Pass newly created schema objects into the `schema={[articleSchema, breadcrumbSchema, ...extraSchemas]}` prop.

Conventions:
- All schema objects must adhere to Schema.org and Google Search Central specifications.
- Never output empty or placeholder arrays in `HowToStep` or `Question` nodes.
