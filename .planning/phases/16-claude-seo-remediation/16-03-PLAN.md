# Plan 16-03: Performance (Speculation Rules API) & E-E-A-T Authority Reinforcements

## Objective
Elevate navigation performance by implementing the W3C Speculation Rules API for instant prefetching/prerendering, and reinforce Google E-E-A-T quality signals by displaying visible fact-checking verification tags and scientific research citations in skincare articles.

## Code Patterns (Model Resilience)
Reference existing files:
- `src/layouts/BaseLayout.astro`: Inject `<script type="speculationrules">` in `<head>`.
- `src/pages/edits/[slug].astro`: Style `article-fact-checked-badge` matching existing aesthetic pill designs (`.cat-pill`, `.meta-item`).
- `src/lib/seeds.ts`: Ground active ingredient descriptions with peer-reviewed literature citations.

Conventions:
- Inline script tag in Astro requires `is:inline`.
- External citation links must carry `rel="noopener noreferrer"`.
