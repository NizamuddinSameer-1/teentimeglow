# Plan 14-01: Direct Media Upload & Admin Persistence APIs

## Objective
Provide the backend engine for Rini's Zero-Tech Admin Studio. Allows direct photo uploads from phone/computer without touching URLs, persistent 30-day "Remember Me" login sessions, full CRUD endpoints for articles, wallpapers, rankings, and quotes, and a settings endpoint for live website text customizations.

## Code Patterns (Model Resilience)
Reference these existing files:
- `src/pages/api/community/submit.ts` — multipart/form-data parsing & Supabase storage upload pattern
- `src/pages/api/admin/publish.ts` — admin session validation & database mutation pattern
- `src/lib/supabase.ts` — `getAdminClient()` for service_role database mutations

Conventions:
- File naming: kebab-case / camelCase
- Admin session guard: verify `ttg_admin_session` cookie against `ADMIN_SECRET_KEY` (default `rini-glow-2026`)
- Return standard JSON responses `{ success: true, data: ... }` or `{ error: string }` with appropriate HTTP status codes.

    1. Import APIRoute from 'astro' and `getAdminClient` from '@/lib/supabase'.

    6. Retrieve public URL via `supabase.storage.from(...).getPublicUrl(...)`.
    7. Return `{ success: true, url: publicUrl, filename: file.name }`.
  </action>

</task>
