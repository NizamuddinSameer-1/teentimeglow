# Plan 14-03: Live Website Text Customizer, Content Modules & Polished Studio UI

## Objective
Assemble the complete, ultra-aesthetic, zero-code Admin Cockpit at `/admin`. Includes a dedicated Live Website Copy Customizer to edit homepage headlines, badges, and stats counters without code; dedicated tabs for managing 4K Wallpapers, Prime Video Rankings, and Daily Quotes with direct photo uploads; and polished mobile-first responsive design with friendly success notifications.

## Code Patterns (Model Resilience)
Reference these existing files:
- `src/config/siteContent.ts` — base fallback content schema
- `src/pages/admin/index.astro` — admin cockpit styles and layout
- `src/components/Hero.astro`, `src/components/StatsStrip.astro` — props and content bindings

Conventions:
- Visual feedback: Floating toast notification system (e.g. *"✨ Saved successfully!"*, *"✦ 4K Wallpaper uploaded to Vault"*) with warm sunset colors.
- Responsive design: Single-column on mobile screens (iPhone Safari) and comfortable multi-column on desktop.
- Confirmation modals: Gentle, friendly confirmation before any delete action.
