# Plan 14-02: Visual Rich-Text Editor & Article Management Studio

## Objective
Build a visual, zero-code article writing and editing studio for Rini. Eliminates all HTML/Markdown by providing a Notion/Instagram-style visual editor with single-click formatting (H2, H3, Bold, Italic, Quotes, Bullet points) and inline photo insertion. Provides a full management dashboard for viewing, editing, and deleting published articles.

## Code Patterns (Model Resilience)
Reference these existing files:
- `src/pages/admin/index.astro` — existing admin tabs and layout structure
- `src/pages/edits/[slug].astro` — article reader layout to ensure format compatibility
- `src/config/siteContent.ts` — styling tokens and aesthetic color palette

Conventions:
- Visual rich-text: Use clean `contenteditable` container with custom toolbar buttons calling `document.execCommand` / DOM APIs for headings and blockquotes.
- Clean HTML sanitization: Strip dangerous scripts while preserving headings, paragraphs, blockquotes, lists, and images.
- Photo Picker: Floating "Insert Photo" button triggers hidden `<input type="file" accept="image/*">`, automatically calls `/api/admin/upload`, and embeds the uploaded image directly into the article text.
