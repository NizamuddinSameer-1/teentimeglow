# Plan 5-1: Rini's Zero-Code Admin Cockpit, Authentication & Publishing System

## Objective
Provide Rini with a private, zero-code moderation and publishing cockpit (`/admin`). Implement secure authentication with `/admin/login`, cookie-based route protection, 1-tap community approval/rejection moderation, and multi-content zero-code publishing (edits, wallpapers, quotes).

## Code Patterns (Model Resilience)
- SSR Protection: `const session = Astro.cookies.get('ttg_admin_session'); if (!session || session.value !== expectedToken) return Astro.redirect('/admin/login');`
- Clean API Endpoints: `POST /api/admin/login` and `POST /api/admin/logout` using Astro's `cookies` helper.
- Admin Client: `getAdminClient()` for service_role database queries and inserts.
- Design System: Reuse TeenTimeGlow brand design tokens (`--font-editorial`, `--sunset-accent`, `--brand-green`, glassmorphism, responsive cards).
