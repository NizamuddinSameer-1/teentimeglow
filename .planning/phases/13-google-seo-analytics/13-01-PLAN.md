# Phase 13: Google SEO, Search Console & Analytics Integration Plan

## Goal
Establish complete search engine discovery, canonical indexing, rich snippet schemas, and traffic analytics tracking for TeenTimeGlow (`https://teentimeglow.me`).

## Core Deliverables
1. **Google Search Console Verification**:
   - Primary domain verification token via DNS TXT record (`google-site-verification=tG2T-OkiuD6VDoDxBltWXnSLnxv3q6qMg2p1kzzT8BQ`).
   - Backup `<meta name="google-site-verification" ...>` in `BaseLayout.astro`.
2. **Robots.txt (`public/robots.txt`)**:
   - Allow crawl access to all public hubs and articles.
   - Disallow private `/admin` dashboard and `/api` routes.
   - Direct link to `https://teentimeglow.me/sitemap.xml`.
3. **XML Sitemap (`public/sitemap.xml`)**:
   - Canonical listing of homepage, `/edits`, `/wallpapers`, `/rankings`, `/quotes`, `/quiz`, `/gallery`.
   - All 6 editorial article slugs with `<lastmod>`, `<changefreq>`, and `<priority>`.
4. **Google Analytics 4 Component (`src/components/Analytics.astro`)**:
   - Asynchronous `gtag.js` loading driven by `PUBLIC_GA_MEASUREMENT_ID`.
   - Non-blocking stub fallback to prevent runtime exceptions when unconfigured.
5. **Canonical URLs & Social Meta in `BaseLayout.astro`**:
   - Dynamic `<link rel="canonical">` to prevent duplicate content indexing.
   - Comprehensive OpenGraph and Twitter card metadata.
6. **Structured Data (JSON-LD)**:
   - `WebSite` & `Organization` on global layout.
   - `BlogPosting` schema on `/edits/[slug]`.
   - `ItemList` schema on `/rankings`.
