# Plan 7-1: Dedicated 4K Wallpaper Vault Standalone Page (`/wallpapers`)

## Objective
Build an immersive, high-fashion standalone page at `/wallpapers` featuring:
1. Editorial hero header with live stats, search bar, and device filter pills (`All`, `iPhone / Mobile`, `Desktop / 4K`).
2. Interactive responsive grid of 4K wallpapers with device aspect ratios, resolution tags, and instant download counter integration (`/api/wallpapers/download`).
3. Wallpaper preview modal with mobile/desktop mockup view.
4. Back-to-home navigation and integration with the brand header.
