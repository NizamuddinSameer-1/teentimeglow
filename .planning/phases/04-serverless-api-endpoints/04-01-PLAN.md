# Plan 4-1: Serverless API Endpoints, Community Submissions & Analytics

## Objective
Implement and verify resilient serverless API handlers in Astro 5 (`output: 'server'`) with `@astrojs/vercel` for user interactions, moderation quarantine (`status: 'pending'`), Supabase storage uploads (`community-pending` bucket), live like counter increments, and wallpaper download analytics.

## Code Patterns (Model Resilience)
- API route export: `export const prerender = false; export const POST: APIRoute = async ({ request }) => { ... }`
- Admin privileges: Use `getAdminClient()` for service_role database inserts and storage bucket uploads to guarantee atomic execution without RLS read/write race conditions.
- Sanitized payloads: Enum validation for categories (`nails`, `diy`, `sketch`, `decor`, `fashion`), size checks, and default fallback images.
- Client micro-interactions: Audio chime synthesis (`playTone`), confetti burst, optimistic DOM updates, and toast alerts.
