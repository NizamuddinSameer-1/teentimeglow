# Plan 3-1: Supabase Database Layer, Resilient Queries & Fallback Seeds

## Objective
Establish and verify the live type-safe Supabase PostgreSQL database integration on project `txuubvzxmawjqqduavcv` across all 9 tables (`posts`, `rankings`, `quizzes`, `quiz_questions`, `quiz_options`, `quiz_outcomes`, `community_creations`, `stories_memes_quotes`, `wallpapers`). Ensure zero-downtime offline fallback seeds and seamless Astro SSR data hydration.

## Code Patterns (Model Resilience)
- Type definitions: strict TypeScript interfaces in `@/types/database.ts`
- Client creation: `@supabase/supabase-js` client with public anon key and optional service role key
- Resilient fetch pattern: `try { const { data, error } = await supabase.from(...); if (error || !data) return fallback; return data; } catch { return fallback; }`
