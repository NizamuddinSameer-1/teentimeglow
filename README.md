# TeenTimeGlow (`teentimeglow.me`)

> **Personal lifestyle, beauty, fashion, home decor, curated rankings & free wallpaper platform for Rini.**

- **Production Domain:** [https://teentimeglow.me](https://teentimeglow.me)
- **Staging / Fallback:** [https://teentimeglow.vercel.app](https://teentimeglow.vercel.app)
- **Tech Stack:** Astro Hybrid + Supabase (PostgreSQL & Auth) + Cloudflare R2 on Vercel Edge.
- **Budget:** $0.00 / 100% Free Forever.
